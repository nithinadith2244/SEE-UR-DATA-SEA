Privacy

This text describes what the software does. The person or organisation running a deployment of it must review it, add who they are, and add anything their local law requires.

What this site stores

Nothing. It sets no cookies, uses no analytics or advertising scripts, and does not use local storage, session storage or IndexedDB. Searches are not saved, there is no search history and there are no accounts. If you reload the page, everything you typed and every result is gone. This site's server does not log or keep addresses.

What happens when you press Check email

The address is sent to a breach-lookup service so it can be checked. By default that is XposedOrNot, a free service that needs no key. Your browser asks it directly, and the address is part of that request, as the service's interface requires. XposedOrNot's own privacy policy applies to what it receives, and this site cannot see or control that.

If your browser cannot reach XposedOrNot directly, the page retries once through this site's own server, which asks XposedOrNot for you and passes the answer back. The server keeps nothing, and it appears to XposedOrNot as the requester, not you.

If the site operator has switched to the paid Have I Been Pwned service instead, the address goes to this site's server, which holds that service's key in a server-only setting, never in your browser, and asks Have I Been Pwned. The page always names the service that is in use beside the search box.

Test mode

An operator using Have I Been Pwned can run a separate test mode that answers only for that service's synthetic test addresses and says so on screen. Test mode refuses real addresses and never shows test data for them.

Hosting

Like any website, the host that serves these pages may keep ordinary server logs of page requests, such as IP address and time. Those logs do not contain what you type into the search box, because it is never sent to the host.

Request limits

To avoid request floods and to respect the free service's limits, the page counts how many checks you have started since it was opened, and the server limits requests per IP address and overall. Both keep only timestamps in memory, never addresses, and forget them on reload or restart.

What we will never ask for

Passwords, authentication codes or account credentials. If anything on or about this site asks for them, do not enter them.
